# 蛇伤急救科普教育 APP — 动画素材库清单

> **技术实现**：纯 CSS @keyframes 动画 + SVG 路径动画（零依赖，无需额外素材文件）
> **代码位置**：
> - 蛇类象形动画：`snake-aid-app/components/SnakeAnim.vue`
> - 急救操作动画：`snake-aid-app/components/FirstAidAnim.vue`
> - 音效合成：`snake-aid-app/utils/audio.js`（Web Audio API，免录音）

---

## 第一部分：12 种蛇象形动画素材库

### 核心技术参数

| 参数 | 数值 | 说明 |
|------|------|------|
| 渲染方式 | SVG + CSS keyframes | 矢量清晰，任何分辨率自适应 |
| 蛇身路径 | 三次贝塞尔曲线 `Q` 指令 | 自然 S 形弯曲 |
| 动画时长 | 0.8s ~ 3s | 不超过注意力极限 |
| GPU 加速 | `transform` / `opacity` 属性 | 无重绘，60fps 流畅 |
| 文件大小 | 0KB（纯代码） | 无加载延迟 |

### 通用动画效果（所有蛇共享）

| 动画名称 | CSS Keyframe | 效果描述 | 时长 |
|---------|-------------|---------|------|
| 🐍 蛇身扭动 | `bodyWave` | 蛇身整体左右扭动前进 | 2s 循环 |
| 🌀 花纹蠕动 | `markCrawl` | 花纹沿蛇身"爬过"的视觉暗示 | 3s 循环 |
| 👅 吐信 | `tongueFlick` | 舌头 `...─...─` 伸出收回 | 0.8s 循环 |
| 🔺 三角头闪烁（毒蛇） | `headGlow` | 头部红光脉冲闪烁，警示危险 | 1.5s 循环 |
| ⭕ 椭圆头微动（无毒） | `headBob` | 头部轻微上下摆动 | 2s 循环 |

## 第二部分：9 步急救操作动画素材库

| 步骤 | 名称 | 动画元素 | 交互 | 音效 |
|------|------|---------|------|------|
| 1 | 🏃 脱离险境 | 蛇 🐍 + 人 👤 + 箭头 ➡️ + 风线 💨💨 | 选正确做法 | sfxCorrect/wrong |
| 2 | 🐍 辨认蛇种 | 三角头 🔺(毒) vs 椭圆头 ⭕(安全) 对比 | 选头型 | sfxCorrect/wrong |
| 3 | 😌 保持镇定 | 深呼吸光圈扩散动画（2 个 ring 延迟 1.5s） | 选心态 | sfxDone |
| 4 | 📞 紧急呼救 | 拨号盘 1-2-0 逐位亮起动画 + 📱 电话震动 | **模拟拨 120** | **sfxEmergency** |
| 5 | 💧 伤口解压 | 水滴 💧💧💧 落下动画 + 伤口闪烁 | 选清洗方式 | sfxClick |
| 6 | 🦿 伤肢制动 | 平放箭头 ➡️ + 🛠️ 夹板提示 | **选摆放位置** | sfxCorrect |
| 7 | 🩹 加压包扎 | **5 层绷带依次缠绕动画**（每层延迟 0.2s） | **拖拽包扎带** | **sfxDone** |
| 8 | 💊 止痛处理 | 药瓶 💊 + 红叉 ❌ 摇晃 | 选哪些药能用 | sfxWrong |
| 9 | 🚫 禁忌清单 | 4 条红叉 ❌ + 1 条绿色 ✅ 对照 | 判断允许/禁止 | sfxCorrect |

### 急救动画通用技术

| 参数 | 数值 |
|------|------|
| 渲染方式 | 纯 CSS + emoji 图标 |
| 容器尺寸 | 默认 280rpx 高度，响应式 |
| emoji 组合 | 利用系统原生 emoji 🐍👤💨❌✅ 零素材 |
| 交互点 | 第 4 步拨号盘 / 第 6 步伤肢摆放 / 第 7 步包扎拖拽 |
| 反馈颜色 | 正确=绿 `#2E7D32`，错误=红 `#C62828` |

## 第三部分：音效素材库（Web Audio API 合成）

> **零录音！** 全部用浏览器原生 Web Audio API 实时合成，**无需任何 mp3/wav 文件**

| 音效名称 | 函数 | 合成参数 | 场景 |
|---------|------|---------|------|
| 点击音 | `sfxClick()` | 800Hz sine wave, 0.08s, volume 0.2 | 按钮点击 |
| 正确反馈 | `sfxCorrect()` | **三连上升音** C5(523)→E5(659)→G5(784), 0.12s each | 答案正确 |
| 错误反馈 | `sfxWrong()` | **两连下降音** 220→150Hz square wave, 0.15s+0.2s | 答案错误 |
| 蛇警告 | `sfxSnake()` | 300→250→200Hz sawtooth, 0.1s each | 蛇出现 |
| 通关庆祝 | `sfxWin()` | 523→659→784→1047Hz triangle, 0.2s each | 游戏通关 |
| 紧急警报 | `sfxEmergency()` | **120 警报声** 880→660→880→660Hz 循环, 0.25s each | 模拟拨 120 |
| 包扎完成 | `sfxDone()` | 440→554→659Hz sine, 0.15s each | 包扎成功 |
| 背景音 | `playBGM()` | **和弦循环** C5→E5→G5→C6 triangle wave, 1.5s each, volume 0.06 | 轻松氛围 |

### 语音合成（方言）

| 方言 | Code | 关键急救短语示例 |
|------|------|----------------|
| 普通话 | `zh-CN` | 「蛇咬伤后保持冷静，立刻远离毒蛇！」 |
| 四川话 | `zh-CN`（方言短语包）| 「遭蛇咬到了莫慌！搞快打幺二零！」 |
| 粤语 | `zh-HK` | 「俾蛇咬咗唔好惊，即刻打一二零！」 |
| 河南话 | `zh-CN`（方言短语包）| 「叫蛇咬着了别慌，赶紧嘞打一百二十！」 |

## 第四部分：全局控制入口

**所有动画/音效/方言/主题** 通过右下角 🛠️ 浮动按钮全局控制：

```
🛠️ 全局设置面板
├── 👁️ 显示模式：标准 | 大字 | 👴老人
├── 🗣️ 语音方言：普通话 | 四川话 | 粤语 | 河南话
├── 🔊 操作音效开/关
├── 🔊 语音朗读开/关
├── 🔊 背景音开/关
└── 🔈 测试语音（当前方言）
```
