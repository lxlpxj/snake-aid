# 蛇伤急救科普教育 APP — 游戏化关卡脚本

> **设计蓝本**：洪恩识字「小步递进、即时反馈、游戏驱动」教学逻辑
> **参考规范**：《中国蛇伤救治指南（2024版）》第 7.1 节现场急救
> **交付要求**：分步闯关 + 容错反馈，每步独立可重试

---

## 第一部分：毒蛇识别「玩-认-练-测」四步认知闭环

### 第 1 步：玩（象形动画 → 建立危险直觉）

| 项目 | 内容 |
|------|------|
| 场景 | 卡片式浏览，每次显示 1 种蛇的 **SVG 动画** |
| 动画 | 蛇身扭动 + 花纹蠕动 + 吐信 + 毒蛇头部红光闪烁 |
| 交互 | 左右滑动切换蛇种 |
| 反馈 | 毒蛇 → 🦷🦷 + 红色警告闪烁 + sfxSnake 警告音 |
| 技术实现 | `SnakeAnim.vue` + `swiper` 组件 |

### 第 2 步：认（记忆保命特征）

| 项目 | 内容 |
|------|------|
| 场景 | Swiper 卡片式，每张卡显示一个蛇种的 **保命记忆口诀** |
| 特征维度 | 头型 / 花纹 / 颜色 / 尾部 / 毒性 |
| 口诀示例 | 「银环蛇：黑白相间+小三角头 → 神经毒 8 小时死亡！」 |
| 交互 | 上一条 / 下一条 大按钮 |
| 技术实现 | `swiper` + 保命记忆卡片 |

### 第 3 步：练（模拟真实决策 · 5 个场景题）

| 场景编号 | 场景描述 | 题目 | 正确答案 |
|---------|---------|------|---------|
| S1 | 傍晚菜地发现 | 菜叶下的蛇什么头型更危险？ | 🔺 三角头 → 毒蛇 |
| S2 | 田埂边遇见 | 灰色条纹蛇有牙齿印？ | 无牙印 → 无毒（菜花蛇） |
| S3 | 河边游泳 | 水里蛇头扁 → 是啥？ | 扁头 → 水蛇（无毒） |
| S4 | 夜间山路上 | 突然踩到蛇怎么办？ | 🔺 站定不动等它走 |
| S5 | 家养鸡舍 | 黑蛇带黄色花纹？ | 菜花蛇（王锦蛇·无毒） |

### 第 4 步：测（场景通关 · 8 题终极测试）

| 题目类型 | 数量 | 分值 | 星级评定 |
|---------|------|------|---------|
| 头型判断 | 2 题 | 15 分/题 | ⭐⭐⭐ 210-180 |
| 花纹判断 | 2 题 | 15 分/题 | ⭐⭐ 179-150 |
| 场景判断 | 2 题 | 20 分/题 | ⭐ 149 以下 |
| 毒性判断 | 2 题 | 20 分/题 | |

## 第二部分：急救流程「9 步闯关」关卡脚本

### 📊 总览表

| 关卡 | 步骤名 | 场景 | 交互方式 | 正确答案 | 反馈 | 分值 |
|------|--------|------|---------|---------|------|------|
| 1 | 🏃 脱离险境 | 被咬瞬间，蛇还在附近 | 3 选 1 | **慢慢后退离开 3-5 米** | ✅ 得 10 分 | 10 |
| 2 | 🐍 辨认蛇种 | 看见蛇的头和花纹 | 3 选 1 头型 | **三角头 = 毒蛇** | ✅ 得 10 分 | 10 |
| 3 | 😌 保持镇定 | 开始慌了，心率 120 | 3 选 1 | **深呼吸 + 坐下/躺下** | ✅ 得 10 分 | 10 |
| 4 | 📞 紧急呼救 | 手机在身边 | **模拟拨 120 按键交互** | 1→2→0 依次按下 | ✅ 警报音 + 15 分 | 15 |
| 5 | 💧 伤口解压 | 伤口还在流血 | 3 选 1 | **清水冲洗 15-20 分钟** | ✅ 得 10 分 | 10 |
| 6 | 🦿 伤肢制动 | 需要固定伤腿/手 | **判断伤肢摆放位置** | **平放低于心脏** | ✅ 得 15 分 | 15 |
| 7 | 🩹 加压包扎 | 需要缠绷带 | **拖拽包扎带交互** | 伤肢近心端包扎 | ✅ sfxDone + 15 分 | 15 |
| 8 | 💊 止痛处理 | 痛得受不了 | 多选 | **❌ 止痛药 ❌ 酒 ❌ 冰敷** | ✅ 得 10 分 | 10 |
| 9 | 🚫 禁忌清单 | 最后检查 | 多选允许/禁止 | 禁止全部 4 项 | ✅ 得 5 分 | 5 |

### 🎬 每关详细脚本

#### **关卡 1：脱离险境**

```
┌──────────────────────────────────────┐
│  🏃 第 1 关：脱离险境                  │
│  ⚠️ 你在田间割草，突然被蛇咬了脚踝！   │
│  [FirstAidAnim:Step1 人跑开+箭头]     │
│                                      │
│  Q: 被咬后应该怎么做？                │
│                                      │
│  ┌──────────────┐ ┌──────────────┐   │
│  │ A. 赶紧跑 🏃  │ │ B. 慢慢退 ←  │   │
│  │   越快越好    │ │   3-5 米      │   │
│  └──────────────┘ └──────────────┘   │
│  ┌──────────────┐                     │
│  │ C. 蹲下抓蛇 🐍│                     │
│  └──────────────┘                     │
└──────────────────────────────────────┘

交互：点击选项
正确答案：B
正确反馈：
  - 视觉：绿色边框 + ✅ + 「做得对！快跑开！」
  - 听觉：sfxCorrect 上升三连音
错误反馈：
  - 视觉：红色边框 + ❌ + 「错！蛇还在攻击范围！」
  - 听觉：sfxWrong 下降音
容错机制：选错可重试，扣分但不打断流程
```

---

#### **关卡 4：紧急呼救（核心交互·模拟拨 120）**

```
┌──────────────────────────────────────┐
│  📞 第 4 关：紧急呼救                  │
│  现在安全了，但需要专业救援！           │
│  [FirstAidAnim:Step4 拨号盘动画]      │
│                                      │
│  📱 点击按键拨打 120                  │
│                                      │
│  ┌─────────────────────────────┐     │
│  │        [ 1 ][ 2 ][ 0 ]       │     │
│  └─────────────────────────────┘     │
│  依次点击数字...                      │
└──────────────────────────────────────┘

交互：依次点击 1 → 2 → 0
正确反馈：
  - 视觉：三个数字依次变亮变绿 + 📞呼叫中...闪烁
  - 听觉：sfxEmergency 警报音
错误反馈（按错数字）：
  - 视觉：红色闪烁 + 重置拨号
  - 听觉：sfxWrong
容错机制：按错任一数字 → 重置重新拨
```

---

#### **关卡 6：伤肢制动（核心交互·判断摆放位置）**

```
┌──────────────────────────────────────┐
│  🦿 第 6 关：伤肢制动                  │
│  让蛇毒扩散慢点！                      │
│  [FirstAidAnim:Step6 伤肢平放动画]    │
│                                      │
│  Q: 被蛇咬的腿应该怎么放？             │
│                                      │
│  🦾 选项 A        🦾 选项 B        🦾 选项 C
│  ────────      ──────────       ═══════
│   抬高高举       平放地面          高于心脏
│   ⬆️ 错误        ➡️ 正确         ⬆️ 错误
└──────────────────────────────────────┘

交互：点击三个示意图之一
正确答案：B 平放地面
正确反馈：
  - 视觉：绿色边框 + ✅ + 「正确！平放制动！」
  - 听觉：sfxCorrect
错误反馈：
  - 视觉：红色边框 + ❌ + 「错！不要抬高！」
  - 听觉：sfxWrong
```

#### **关卡 7：加压包扎（核心交互·拖拽包扎带）**

```
┌──────────────────────────────────────┐
│  🩹 第 7 关：加压包扎                  │
│  [FirstAidAnim:Step7 绷带缠绕动画]    │
│                                      │
│  💡 把包扎带拖到：伤口近心端 5-10cm    │
│                                      │
│  [       🦿       ] ← 拖拽区域         │
│      ══════════                       │
│      包扎带                            │
└──────────────────────────────────────┘

交互：触摸/鼠标拖拽包扎带到正确位置
正确反馈：
  - 视觉：5 层绷带依次缠绕动画（每层延迟 0.2s）
  - 听觉：sfxDone 三音上升
  - 文字：「包扎完美！继续！」
错误反馈（位置错）：
  - 视觉：红色闪烁 + 「错！要在伤口上方（近心端）」
容错机制：拖错位置可重新拖
```
