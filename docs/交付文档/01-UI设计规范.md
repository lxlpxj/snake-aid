# 蛇伤急救科普教育 APP — UI 设计规范

> **目标用户**：农村中老年低学历群体（55岁+，小学/初中文化水平）
> **设计基准**：WCAG 2.1 AA 无障碍标准，老人高对比度+大字号

---

## 一、字号规范（rpx 单位，uni-app 标准）

| 类名 | 基准值 | 老人模式(1.4x) | 用途 | WCAG 合规 |
|------|--------|---------------|------|-----------|
| `.text-mini` | 24rpx | 34rpx | 辅助说明、角标 | - |
| `.text-small` | 26rpx | 36rpx | 次要文字、标签 | - |
| `.text-body` | **30rpx** | **42rpx** | 🔴 正文 | ✅ AA (16px) |
| `.text-title` | 34rpx | 48rpx | 小标题 | ✅ AA (18px) |
| `.text-heading` | **40rpx** | **56rpx** | 🔴 页面标题 | ✅ AAA (22px) |
| `.text-big` | 48rpx | 67rpx | 大标题 | ✅ AAA |
| `.text-huge` | **60rpx** | **84rpx** | 🔴 核心数字/得分 | ✅ AAA |

**换算公式**：1rpx = 0.5px（iPhone 6/7/8 基准），1rpx = 屏幕宽度 / 750

| 模式 | 前景色 | 背景色 | 对比度比值 | 达标级别 | 适用场景 |
|------|--------|--------|-----------|---------|---------|

## 三、色彩体系

### 3.1 主色板（合同要求：高对比度）

| 色彩角色 | HEX | RGB | 用途 |
|---------|-----|-----|------|
| 🔴 主色-紧急红 | `#E53935` | 229, 57, 53 | 毒蛇标签、危险警告、首页入口 |
| 🟠 辅助色-警戒橙 | `#FF6F00` | 255, 111, 0 | 四步学习、积分、提示 |
| 🟢 安全色-急救绿 | `#2E7D32` | 46, 125, 50 | 无毒蛇、安全提示、成功反馈 |
| 🔵 信息色-医疗蓝 | `#1565C0` | 21, 101, 192 | 医院位置、AI 助手 |
| ⚫ 正文色 | `#212121` | 33, 33, 33 | 所有正文 |
| ⚪ 背景色 | `#FFFFFF` | 255, 255, 255 | 卡片、页面 |
| ⚪ 次背景 | `#F5F5F5` | 245, 245, 245 | 分组、列表 |

### 3.2 语义化配色（直观传达含义）

| 场景 | 颜色 | 理由（老人直觉） |
|------|------|----------------|
| 毒蛇/危险 | 🔴 红色 + ⚠️ 三角 | 红灯停、警告标牌本能反应 |
| 无毒/安全 | 🟢 绿色 + ✅ 圆圈 | 绿灯行、OK 手势联想 |
| 紧急呼救 | 🔴 红背景 + 白字 | 救护车、火警警报器颜色 |
| 得分/积分 | 🟡 金色 | 金钱、奖励、中奖联想 |
| 正确反馈 | 🟢 绿底 + 🎵 上升音 | "对了！好样的" |
| 错误反馈 | 🔴 红底 + 📢 下降音 | "不对，再试" |

## 四、布局规范（合同要求：单任务线性导航）

```
┌─────────────────────────────────┐
│  状态栏 (44px)                    │ ← 系统时间/电量
├─────────────────────────────────┤
│  导航栏 (88rpx)                   │ ← 返回/标题/更多
├─────────────────────────────────┤
│                                  │
│  内容区 (自适应, 最小 600rpx)     │ ← 单任务卡片，每次只看 1 个
│                                  │
│  卡片圆角: 20rpx                  │
│  卡片内边距: 24rpx                │
│  卡片间距: 16rpx                  │
│                                  │
├─────────────────────────────────┤
│  操作按钮区 (120rpx)              │ ← 固定在底部
├─────────────────────────────────┤
│  TabBar (100rpx)                  │ ← 首页/蛇类/指南/我的
└─────────────────────────────────┘
```

### 4.2 触摸目标（合同要求：大按钮）

| 元素 | 最小尺寸 | 推荐尺寸 | 说明 |
|------|---------|---------|------|
| 普通按钮 | 88×88rpx | 120×120rpx | 至少 44×44pt (WCAG) |
| 主要操作按钮 | 300×88rpx | 400×96rpx | 占屏幕宽度 2/3 |
| 图标按钮 | 120×120rpx | 140×140rpx | 老人手指 15mm 直径 |
| 列表项点击区 | 全宽 | - | 不要只点文字 |

## 五、单任务线性导航（洪恩识字模式）

```
         ┌────────────┐
         │  Step 1    │ ← 只显示当前 1 个任务
         │  脱离险境  │
         │  [开始]    │
         └─────┬──────┘
               │ 完成
               ▼
         ┌────────────┐
         │  Step 2    │ ← 上一个自动收起
         │  辨认蛇种  │
         │  [下一个]  │
         └─────┬──────┘
               │ 完成
               ▼
         ┌────────────┐
         │  Step 3    │
         │  ...       │
         └────────────┘

特点：
✅ 一次只聚焦一个任务（认知负荷最小化）
✅ 上一步结果自动收起（不干扰当前）
✅ 每步有"下一个"大按钮（线性推进不迷路）
✅ 进度条在顶部（知道自己在哪）
```

## 六、视觉反馈规范（合同要求：即时反馈）

| 反馈类型 | 视觉 | 听觉 | 时机 |
|---------|------|------|------|
| 点击按钮 | 缩放 95% + 高亮 | 短促 click 音 (800Hz) | 按下瞬间 |
| 答案正确 | 绿色边框 + ✅ 图标 | 上升三连音 (C-E-G) | 0.1 秒内 |
| 答案错误 | 红色边框 + ❌ 图标 + 震动 | 下降两连音 (220→150Hz) | 0.1 秒内 |
| 通关完成 | 星级星星 + 积分弹出 | 上升四连音 + 背景音渐强 | 完成瞬间 |
| 紧急警告 | 红色闪烁 + ⚠️ 放大 | 警报音 (880→660Hz 循环) | 出现瞬间 |

## 七、主题系统（GlobalTools 一键切换）

| 模式名 | 字号放大 | 对比度 | 主色 | 适用场景 |
|--------|---------|--------|------|---------|
| 标准 | 1.0x | 4.5:1 | #E53935 | 普通用户 |
| 大字 | 1.3x | 7:1 | #C62828 | 视力不佳 |

**切换方式**：全局右下角 🛠️ 按钮 → 显示模式 → 一键切换，即时生效

## 八、设计原则总结（降维老年版）

```
原原则          →  老年版降维
─────────────────────────────
极简主义        →  一屏一事，无干扰
视觉层次        →  字号差≥10rpx，颜色差≥40%
色彩丰富        →  语义化配色（红=危险绿=安全）
交互动效        →  反馈滞后<0.1秒，动画≤1秒
```
